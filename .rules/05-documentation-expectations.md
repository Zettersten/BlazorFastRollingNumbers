# Documentation expectations

## README must include
- What the component does and **when to use it**
- Installation + integration steps
- Common examples (basic, styling, easing/duration, accessibility)
- Performance notes and constraints (e.g. `MinimumDigits` clamping)

## CHANGELOG rules
- Use **Keep a Changelog** format.
- Document:
  - breaking changes
  - new features
  - fixes
  - performance changes
